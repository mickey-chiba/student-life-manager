# Campus Compass

学生生活の授業、課題、テスト、予定を一元管理するWebアプリです。ユーザーごとにアカウントを作り、各自のデータを別々に管理できます。

## ローカルでの起動

```bash
npm install
npm start
```

ブラウザで `http://localhost:3000` を開き、新規登録してください。ローカルでは登録内容を `data/store.json` に保存します。このファイルはGitHubには保存されません。

## 公開環境の仕組み

公開環境では `DATABASE_URL` を設定するとPostgreSQLに保存します。初回起動時に必要なテーブルを自動作成するため、手動でSQLを実行する必要はありません。

本番環境では、次の環境変数が必須です。

| 変数 | 説明 |
| --- | --- |
| `NODE_ENV` | 本番では `production` |
| `SESSION_SECRET` | 32文字以上のランダムな文字列 |
| `DATABASE_URL` | PostgreSQLの接続URL |
| `PORT` | 公開サービスから自動設定されるため通常は設定不要 |

`SESSION_SECRET` やデータベースの接続情報は、GitHubに直接書かず、公開サービスの環境変数に設定してください。

## Renderで公開する

Renderの画面でどのボタンを押すかを含む詳しい手順は、[Render公開手順書](RENDER_GUIDE.md) を参照してください。

このリポジトリの `render.yaml` を使うと、次のものが自動作成されます。

- アプリを動かすWebサービス
- データを保存するPostgreSQL
- ログイン状態を安全に保つ `SESSION_SECRET`

公開先ではHTTPSへの転送、Secure Cookie、セキュリティ用HTTPヘッダー、ログイン回数制限、入力値チェックが有効になります。

> Renderの無料PostgreSQLは作成から30日で期限切れになります。継続利用する場合は、期限前にRender上でデータベースを有料プランへ変更してください。

## データについて

- パスワードはscryptでハッシュ化して保存します。
- ユーザーごとに時間割・課題・テスト・予定・設定を分離します。
- ローカルの `data/store.json` は、公開先のPostgreSQLには自動転送されません。
- 公開先は最初は空の状態で始まり、公開ページ上で新規登録して使用します。
