# Campus Compass

学生生活の授業、課題、テスト、予定を一元管理するWebアプリです。ユーザーごとにアカウントを作り、各自のデータを別々に管理できます。

## 起動方法

```bash
npm install
npm start
```

ブラウザで `http://localhost:3000` を開いてください。最初に **新規登録**（名前＋パスワード）をすると、あなた専用の管理ページが作られます。

## アカウントとデータ

- 利用者は名前とパスワードで登録・ログインします。パスワードは scrypt でハッシュ化して保存されます。
- 各ユーザーのデータ（時間割・課題・テスト・予定・設定）は分離され、本人だけが閲覧・編集できます。
- 登録内容はすべて `data/store.json` に保存されます（このファイルは Git 管理対象外）。

## 環境変数

| 変数 | 説明 |
| --- | --- |
| `PORT` | 待ち受けポート（既定: 3000） |
| `SESSION_SECRET` | セッションCookieの署名キー。**本番では必ず設定してください。** 未設定の場合は `data/store.json` 内に自動生成して保存します。 |
| `NODE_ENV` | `production` にすると Cookie に `Secure` 属性が付きます（HTTPS公開時に推奨）。 |

## 公開（デプロイ）時の注意

データは `data/store.json` というファイルに保存されます。再起動時にファイルが初期化されるタイプの無料ホスティングでは登録内容が消えるため、**永続ディスクのあるホスティング**を使うか、データベースへの移行を検討してください。
